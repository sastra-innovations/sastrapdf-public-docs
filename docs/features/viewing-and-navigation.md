# Viewing and Navigation

Viewing and navigation features help users inspect documents before editing, extraction, comparison or workflow execution. They support practical review of large and complex PDFs without implying unrestricted document access.

## Verified Capabilities

| Capability | Status | Notes |
| --- | --- | --- |
| PDF viewing | Implemented | Displays document pages for review and editing. |
| Page thumbnails | Implemented | Provides quick visual navigation across pages. |
| Tiled rendering | Implemented | Supports efficient viewing of larger pages. |
| In-document text search | Implemented | Searches available text or extracted content. |
| Document metadata view | Implemented | Shows public document information when available. |
| Bookmark or outline editing | Implemented | Supports navigation structure changes. |
| Initial view preferences | Implemented; validation pending | Defines how a document opens in compatible viewers. |

## Boundaries

Viewing does not override document permissions. Search over scanned documents may require OCR first, and metadata may be incomplete or inaccurate if the source document does not provide reliable information.
