# Conversion and Export

SastraPDF supports conversion and export operations for document preparation, downstream reuse and workflow distribution. Conversion output should be reviewed because layout, fonts, tables and scanned content can affect fidelity.

## Verified Capabilities

| Capability | Status | Notes |
| --- | --- | --- |
| PDF to DOCX | Implemented | Exports PDF content to Word format. |
| PDF to PPTX | Implemented; validation pending | Produces slide-oriented output. |
| PDF to XLSX or CSV | Implemented; validation pending | Extracts table-oriented content into spreadsheet formats. |
| PDF to HTML | Implemented; validation pending | Exports web-oriented content. |
| PDF to Markdown | Implemented; validation pending | Produces readable structured text. |
| PDF to text | Implemented | Produces plain text where content is available. |
| PDF to image | Implemented | Renders pages as image files. |
| PDF to PDF/A | Implemented; validation pending | Creates an archival-oriented candidate output. |
| PDF to EPUB | Implemented; validation pending | Produces e-book style output for structured documents. |
| Markdown to PDF | Implemented; validation pending | Converts Markdown content into PDF. |
| Image to PDF | Implemented | Converts images into PDF documents. |
| Office file to PDF | Implemented; validation pending | Converts office documents into PDF. |
| Batch conversion | Implemented; validation pending | Converts multiple files through one workflow. |

## Validation Guidance

Conversion is not a guarantee of pixel-perfect output. Users should review converted files before contractual, regulatory, financial or external publication use.

Related pages: [batch processing](batch-processing.md), [comparison and quality review](comparison-and-quality-review.md).
