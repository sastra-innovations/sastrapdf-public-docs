# Page Organization

Page organization features let users restructure documents for review, filing, distribution or downstream processing. SastraPDF treats these as document operations, while approvals and policy gates belong to MedhaOS when governed workflows are enabled.

## Verified Capabilities

| Capability | Status | Notes |
| --- | --- | --- |
| Merge PDFs | Implemented | Combines multiple documents into one output. |
| Split PDF | Implemented | Produces separate files from page ranges. |
| Extract pages | Implemented | Creates a new document from selected pages. |
| Reorder pages | Implemented | Changes page sequence. |
| Rotate pages | Implemented | Adjusts page orientation. |
| Delete pages | Implemented | Removes selected pages. |
| Insert pages | Implemented | Adds pages from another source or blank-page workflow. |
| Duplicate pages | Implemented | Copies pages inside a document. |
| Crop pages | Implemented | Adjusts visible page area. |
| Resize or scale pages | Implemented; validation pending | Adjusts dimensions or scale. |
| Split page regions | Implemented; validation pending | Divides page regions for specialized layouts. |
| Merge pages into a single page | Implemented; validation pending | Combines page content into one page layout. |
| Remove blank pages | Implemented; validation pending | Cleans low-content pages with recommended review. |
| N-up page layout | Implemented; validation pending | Places multiple pages on one output page. |
| Single long-page output | Implemented; validation pending | Produces a continuous-page representation. |
| Overlay documents | Implemented; validation pending | Layers one document or page over another. |
| PDF portfolio creation | Implemented; validation pending | Packages related files or documents into a portfolio PDF. |
| Template and master page management | Implemented; validation pending | Reuses page structures and templates. |
| Mail merge | Implemented; validation pending | Generates personalized document outputs from structured data. |

## Review Guidance

Page operations can affect bookmarks, links, forms, signatures and annotations. Users should review output before relying on it in legal, regulated or customer-facing processes.
