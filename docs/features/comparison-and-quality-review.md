# Comparison and Quality Review

Comparison and quality review features help users evaluate document differences, validate standards candidates and inspect output quality after editing, conversion or workflow processing.

## Verified Capabilities

| Capability | Status | AI-assisted | Notes |
| --- | --- | --- | --- |
| Visual comparison | Implemented; validation pending | No | Compares document appearance. |
| Text or semantic comparison | Implemented; validation pending | Yes | Compares textual or meaning-level changes with review required. |
| Validation profile or preflight check | Implemented; validation pending | No | Applies public-safe quality checks without exposing rule internals. |
| PDF/A validation | Implemented; validation pending | No | Checks archival-oriented candidates. |
| PDF/E validation | Implemented; validation pending | No | Checks engineering PDF candidates. |
| PDF/VT validation | Implemented; validation pending | No | Checks transactional PDF candidates. |
| PDF/UA analysis | Implemented; validation pending | No | Assesses accessibility-related structure. |
| Accessibility tagging and reading order | Implemented; validation pending | No | Improves accessibility structure with human review. |

## Limitations

Quality findings are evidence for review, not a regulatory certification. Accessibility, archive, legal and compliance determinations remain subject to independent validation by the organization.
