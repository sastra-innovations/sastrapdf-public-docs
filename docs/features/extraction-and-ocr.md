# Extraction and OCR

Extraction and OCR features turn document content into usable text, images, layout signals, tables, fields and structured summaries. These capabilities support document intelligence workflows and often require human review for critical decisions.

## Verified Capabilities

| Capability | Status | AI-assisted | Notes |
| --- | --- | --- | --- |
| Text extraction | Implemented | No | Extracts machine-readable text. |
| OCR searchable PDF | Implemented; validation pending | Yes | Recognizes text from scanned pages or images. |
| Image extraction | Implemented | No | Extracts embedded images. |
| Scanned-image extraction | Implemented; validation pending | No | Exports page images or scan images. |
| Layout extraction | Implemented; validation pending | Yes | Extracts layout structure for downstream processing. |
| Table extraction | Implemented; validation pending | Yes | Produces structured table output where the document permits. |
| Document information extraction | Implemented; validation pending | Yes | Extracts key fields or document details. |
| Scan cleanup | Implemented; validation pending | Optional | Improves scanned document readability. |
| Photo or document detection | Implemented; validation pending | Yes | Detects photo-like or document-like inputs for review workflows. |

## Human Review

OCR, layout recognition, table extraction and key information extraction are assistive. Public documentation does not claim complete extraction reliability, complete output quality or error-free results.
