# SastraPDF Feature Catalogue

This catalogue lists public-safe SastraPDF features and operations verified from current product documentation, UI-visible surfaces and internal feature inventories. It omits implementation internals and uses conservative status wording for features that still require workflow, enterprise or founder validation.

## Status Labels

- `Implemented`
- `Implemented; validation pending`
- `Beta preparation`
- `Planned`
- `Founder verification required`

## Operation Counting Method

The published document-operation count is calculated by counting rows where `Category` is `Document operation` and `Status` is either `Implemented` or `Implemented; validation pending`. The current count is **105 distinct document operations**.

Rows categorized as `AI`, `collaboration`, `workflow` or `platform` are not counted as document operations. Duplicate UI and API access to the same capability is counted once.
