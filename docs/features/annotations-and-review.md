# Annotations and Review

Annotations and review features support collaborative document inspection, comments, notes, stamps and review evidence. They are part of SastraPDF's collaborative editing surface and should be governed by workspace permissions.

## Verified Capabilities

| Capability | Status | Notes |
| --- | --- | --- |
| Create, edit or delete annotations | Implemented | Adds and manages document review marks. |
| Annotation search | Implemented | Finds annotations by available content or type. |
| Annotation templates | Implemented; validation pending | Reuses common review markings. |
| Sticky notes | Implemented | Adds note-style review context. |
| Remove annotations | Implemented; validation pending | Cleans or finalizes reviewed documents. |
| XFDF import and export | Implemented; validation pending | Exchanges annotation data with compatible tools. |
| Stamp document | Implemented | Adds reusable review or approval stamps. |
| Comments and replies | Implemented | Supports discussion threads in collaborative review surfaces. |

## Governance Considerations

Review activity should preserve reviewer identity, document access boundaries and, where required, approval evidence. A stamp or comment is not automatically a formal approval unless the workflow defines it as one.
