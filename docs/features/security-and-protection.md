# Security and Protection

Security and protection features help prepare, inspect and control documents. They are document controls, not compliance certifications or guarantees of legal compliance.

## Verified Capabilities

| Capability | Status | Notes |
| --- | --- | --- |
| Encrypt or password-protect PDF | Implemented | Applies document protection settings. |
| Remove document password | Implemented | Removes protection when the user is authorized and supplies valid credentials. |
| Permission analysis | Implemented; validation pending | Inspects document permission settings. |
| Sanitize PDF | Implemented; validation pending | Removes unsafe or unwanted active content where supported. |
| Digital signing | Implemented; validation pending | Supports signing workflows with validation needs. |
| Signature certificate and audit export | Implemented; validation pending | Provides signing evidence for review. |
| PDF/A validation | Implemented; validation pending | Checks archival-oriented conformance candidates. |
| PDF/X preflight | Implemented; validation pending | Checks print-oriented conformance candidates. |
| PDF/E validation | Implemented; validation pending | Checks engineering PDF candidates. |
| PDF/VT validation | Implemented; validation pending | Checks variable or transactional PDF candidates. |
| PDF/UA analysis | Implemented; validation pending | Assesses accessibility-related structure. |
| Form action and event inspection | Implemented; validation pending | Helps review active document behavior. |

## Governance Boundary

SastraPDF presents document security operations. Documents and Security retain their respective document and containment effects; Identity, Accounts, Tenancy, Action Access, Policy, Decision and Audit retain assurance, membership, placement, permission, policy, approval-disposition and proof effects. MedhaOS governs controlled execution when integrated. These controls can support an organization's governance program but do not automatically make an organization compliant.
